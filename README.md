# Веб-генератор графов: 5 алгоритмов дискретной математики

## О проекте

Проект представляет собой веб-приложение для генерации графов и проверки знаний по пяти классическим алгоритмам теории графов.

Разработан в рамках проектной деятельности. Позволяет генерировать случайные графы, вводить ответы (с 3 попытками), получать подсказки и пошаговые решения.

## Реализованные алгоритмы

| Номер | Задание | Алгоритм |
|-------|---------|----------|
| 1 | Компоненты сильной связности | Матричный метод (транзитивное замыкание) |
| 2 | Фронт волны | Флойд-Уоршелл (диаметр, радиус, центры) |
| 3 | Форд-Беллман | Поиск кратчайшего пути в нагруженном графе |
| 4 | Эйлерова цепь | Алгоритм Флёри / Хирхольцера |
| 5 | Минимальное остовное дерево | Алгоритм Краскала (DSU) |

## Возможности

- Генерация графов с регулируемым числом вершин (4–8)
- 3 попытки на ввод ответа, после ошибок показывается верный ответ
- Кнопка «?» — матрица смежности (задания 1,2,4) или матрица весов (3,5)
- Кнопка «Показать решение» — пошаговый вывод с матрицами и пояснениями
- Тёмная / светлая тема (сохраняется в localStorage)
- Визуализация графа с поддержкой двойных ориентированных рёбер
- Адаптивная вёрстка

## Технологии

- HTML5 — структура страницы
- CSS3 — стилизация, тёмная тема, адаптив
- JavaScript (ES6) — вся логика, алгоритмы, отрисовка на canvas
- Canvas API — визуализация графов

## Как пользоваться

1. Выберите задание (1–5)
2. С помощью ползунка задайте количество вершин (4–8)
3. Нажмите «Сгенерировать новый граф»
4. Введите ответ в указанном формате
5. Нажмите «Проверить» — у вас 3 попытки
6. При необходимости воспользуйтесь кнопками:
   - «?» — матрица смежности / весов
   - «Показать решение» — пошаговое объяснение
